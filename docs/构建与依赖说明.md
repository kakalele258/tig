# 构建与依赖说明

## 1. 环境要求

| 项 | 版本 | 说明 |
| --- | --- | --- |
| 操作系统 | Ubuntu 22.04 LTS x86-64 | 脚本 `scripts/setup_ubuntu22.sh` 会校验 `ID=ubuntu`、`VERSION_ID=22.04`、`dpkg --print-architecture=amd64` |
| CMake | >= 3.22 | 实测 3.22.1 |
| 编译器 | 支持 C++20 | 实测 g++ 11.4.0 |
| OpenCV | 4.5.4 | `apt install libopencv-dev` |
| OpenVINO | 2024.4.0 | Intel 官方源，见下 |
| Eigen3 / Ceres / Boost / glog / gflags | 系统源 | 见 `scripts/setup_ubuntu22.sh` |
| Sophus | 1.22.10 | 脚本内源码编译 |

## 2. 一键安装

```bash
sudo ./scripts/setup_ubuntu22.sh
```

脚本会：装 apt 依赖、配 Intel OpenVINO 源、源码编译 Sophus、做一次干净的 CMake 配置与演示视频解码检查。
只想检查不安装用 `--check`，看帮助用 `--help`。

## 3. 两个需要手动补齐的依赖

上游仓库有两个地方会让干净 clone 构建失败，本仓库提供脚本处理：

### 3.1 Foxglove SDK 静态库（`libfoxglove.a`）

上游 `.gitignore` 里 `*.a` 把 `src/core/utility/foxglove/lib/libfoxglove.a` 忽略了，导致链接报：

```
No rule to make target '../src/core/utility/foxglove/lib/libfoxglove.a'
```

对应 Foxglove SDK 版本 **v0.16.1**（其 `foxglove-c.h` 与仓库内头文件逐字节一致）：

```bash
./scripts/fetch_foxglove_sdk.sh
```

### 3.2 flatbuffers 25.2.10 头文件

自动生成的 `autogenerated_flatbuffers/*_generated.h` 里有：

```cpp
static_assert(FLATBUFFERS_VERSION_MAJOR == 25 && FLATBUFFERS_VERSION_MINOR == 2 ...);
```

而 Ubuntu 22.04 源里只有 1.12.1，会编译失败。需要源码安装 25.2.10 的头文件（只需头文件）：

```bash
sudo ./scripts/fetch_flatbuffers.sh
```

安装到 `/usr/local/include/flatbuffers`，gcc 搜索顺序优先于 `/usr/include`。

## 4. 构建与运行

```bash
cd RP-26Rune
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 4
./run_demo.sh              # 带界面
./run_demo.sh --headless   # 无桌面环境
```

> 若要用 Daedalus 仿真桥接插件，配置时需加
> `-DCMAKE_PREFIX_PATH=<daedalus-sim-src>/build/sim-sdk-install`，
> 因为 `daedalus_camera_manager` / `daedalus_send_encoder` 依赖 `find_package(DaedalusSimSdk)`。

## 5. 运行配置切换

| 配置 | 用途 | 启动方式 |
| --- | --- | --- |
| `config/runtime_config.json` | 回放视频拓扑（默认） | `./run_demo.sh` |
| `config/runtime_config_daedalus.json` | Daedalus 仿真拓扑 | `RP_RUNTIME_CONFIG=config/runtime_config_daedalus.json ./output/app` |
| `config/power_rune.json` | 真机/回放算法参数 | 默认 |
| `config/power_rune_sim.json` | 仿真内参（`fx=1303.675`，`cx=720`，`cy=540`） | `RP_POWER_RUNE_CONFIG=config/power_rune_sim.json` |

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `No rule to make target '...libfoxglove.a'` | 上游未提交静态库 | 见 3.1 |
| `static_assert failed: Non-compatible flatbuffers version` | flatbuffers 版本不符 | 见 3.2 |
| 某个插件日志出现一次就再无输出 | 上游插件 `process()` 没取到数据就 `return`，下游阻塞等待导致流水线停滞 | 图像源插件必须在 `process()` 内阻塞等到下一帧再返回 |
